# Plan: Implement Task View Modes (Today, Upcoming, All Tasks, Completed)

## Overview
Add filtering modes to the Todos Index page to show: Today (due today or overdue), Upcoming (due in future), All Tasks, and Completed.

## Changes Required

### 1. Backend - TodosController.cs
- Add a `viewMode` parameter to the `Index` action (enum: Today, Upcoming, All, Completed)
- Implement filtering logic in the query:
  - **Today**: Todos where `DueDate` is today or `IsDone` is false with no due date, or overdue todos
  - **Upcoming**: Todos where `DueDate` is in the future and `IsDone` is false
  - **All Tasks**: All todos (current default behavior)
  - **Completed**: Todos where `IsDone` is true

### 2. Frontend - Views/Todos/Index.cshtml
- Update the title to be dynamic based on selected mode
- Add a mode selector (tabs or dropdown) with options: Today, Upcoming, All Tasks, Completed
- Preserve selected mode in navigation between views

### 3. Shared/_Layout.cshtml or Index.cshtml
- Add the mode selector navigation, styled appropriately

## Implementation Details

### ViewMode Enum
Create a `ViewMode` enum in the Models folder with values: All, Today, Upcoming, Completed.

### Controller Changes (TodosController.cs)
```csharp
public enum ViewMode { All, Today, Upcoming, Completed }

public async Task<IActionResult> Index(int? projectId, ViewMode? viewMode = null)
{
    var today = DateTime.Today;
    var todosQuery = _context.Todos.Include(t => t.Project).OrderByDescending(t => t.Priority).ThenByDescending(t => t.CreatedAt).AsQueryable();
    
    // Project filter
    if (projectId.HasValue)
        todosQuery = todosQuery.Where(t => t.ProjectId == projectId.Value);
    
    // View mode filter
    switch (viewMode)
    {
        case ViewMode.Today:
            todosQuery = todosQuery.Where(t => !t.IsDone && (t.DueDate.HasValue ? t.DueDate.Value.Date <= today : true));
            break;
        case ViewMode.Upcoming:
            todosQuery = todosQuery.Where(t => !t.IsDone && t.DueDate.HasValue && t.DueDate.Value.Date > today);
            break;
        case ViewMode.Completed:
            todosQuery = todosQuery.Where(t => t.IsDone);
            break;
        case ViewMode.All:
        default:
            // No additional filter
            break;
    }
    
    // ... rest of method
}
```
